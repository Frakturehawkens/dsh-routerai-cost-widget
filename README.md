# routerai-cost-widget

Плагин DeepSeek Harness: компактная пилюля в нижней панели Web UI
(`conversation.composer.dock`, `order: 2`) рядом с нативным токен-каунтером.

- Показывает **самого дешёвого провайдера** RouterAI для активной модели сессии
  и **стоимость этой сессии** в рублях.
- По клику открывает поповер со всеми провайдерами модели, их ценами
  (вход / кэш / выход) и стоимостью именно этой сессии.

## Что где считается

| Слой | Ответственность |
|---|---|
| Host (`index.js` + `lib/`) | сессия, usage, запросы к RouterAI, кэш на диске |
| Client (`client.js`) | только отрисовка: слот, пилюля, поповер |

Клиент не имеет доступа к сессии и не может ходить в `routerai.ru` (CORS),
поэтому данные он получает со своего же origin.

**Важно:** RouterAI отдаёт цены уже в рублях за токен (`pricing.prompt ≈ 3.5e-5`
= ~35 ₽ за 1 млн), поэтому стоимость считается сразу в ₽. Курс валют не
запрашивается и не применяется.

## Маршруты

| Метод, путь | Ответ |
|---|---|
| `GET /routerai-cost-widget/state?sessionId=…` | модель, usage, провайдеры с ценами и стоимостью |
| `POST /routerai-cost-widget/refresh?sessionId=…` | то же, принудительно обновляет цены этой модели |

Цены RouterAI кэшируются на час (память + `<DSH_PROFILE_DIR>/.routerai-cost-widget/cache.json`).
Кнопка Refresh сбрасывает только цены.

## Конфигурация

| Поле | По умолчанию | Смысл |
|---|---|---|
| `apiBase` | `https://routerai.ru/api/v1` | база API RouterAI |
| `modelAliases` | `{}` | ручной маппинг id модели сессии на id каталога RouterAI |

## Ограничения

- Тариф `time-of-day` в `variable_pricings` применяется по UTC: `utc_start`/`utc_end`
  трактуются как сотые доли часа (`1400` = 14:00), `utc_end = 0` при ненулевом
  `utc_start` — до полуночи, `0`/`0` — весь день. Это вывод из данных API,
  а не документированный контракт.
- Стоимость считается по фактическому usage сессии; ретраи без usage не учитываются.
- Версия схемы файла кэша — 2. Файл версии 1 (в нём ещё был курс ЦБ `fx`)
  игнорируется и перезаписывается на первом же обращении: мёртвый ключ в новый
  кэш не переезжает.

## Проверка

```bash
# 55 тестов: кэш, цены, usage, стоимость, маршруты, таймауты
node --test

# холодный старт с диска + офлайн-фолбэк (stale)
node scripts/offline-check.mjs
```

`offline-check.mjs` берёт реальный файл кэша профиля, поднимает свежий экземпляр
`lib/cache.js` (как после рестарта Host'а) и подменяет `fetch` на бросающий:
цены должны прийти с диска, а после истечения TTL — прийти с `stale: true`.

## Аудит и dev-only файлы

`scripts/` и `test/` — только для разработки, в поставку они не входят
(`package.json.files`). Статический аудит свежего клона (`scan_plugin`,
`scanBasis: git`) увидит в них `process.exit` и `rmSync` и может дать
`critical` — это ложное срабатывание по границе артефакта, а не дефект плагина:
аудит поставки (`scanBasis: npm`, по `files`) даёт `clean`.
